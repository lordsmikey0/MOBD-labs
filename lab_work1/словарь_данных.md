# Словарь данных — маркетплейс

Сокращения в столбце «Ограничения»:

- **PK** — первичный ключ
- **FK → таблица.столбец** — внешний ключ
- **UQ** — уникальное значение
- **NN** — `NOT NULL`
- **DEF x** — значение по умолчанию `x`
- **CK** — `CHECK`-ограничение
- **IDENTITY** — автоинкремент (`GENERATED BY DEFAULT AS IDENTITY`)

---

## 1. `users` — пользователи системы

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Суррогатный идентификатор пользователя |
| `full_name` | `varchar(128)` | NN | ФИО пользователя |
| `email` | `varchar(255)` | NN, UQ | Email (логин), уникален в системе |
| `phone` | `varchar(30)` | — | Телефон; может отсутствовать |
| `role` | `varchar(30)` | NN, DEF `'customer'`, CK `IN ('customer','seller','admin')` | Роль в системе |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата регистрации |

---

## 2. `sellers` — продавцы (магазины)

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор магазина |
| `user_id` | `integer` | NN, UQ, FK → `users.id` (CASCADE) | Владелец магазина; один пользователь — один магазин |
| `store_name` | `varchar(255)` | NN | Название магазина |
| `description` | `text` | — | Описание магазина |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата создания магазина |

---

## 3. `categories` — категории товаров

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор категории |
| `parent_id` | `integer` | FK → `categories.id` (SET NULL) | Родительская категория; `NULL` — корневая |
| `name` | `varchar(100)` | NN | Название категории |

> Таблица самоссылочная — реализует иерархию категорий («Электроника → Смартфоны → …»).

---

## 4. `products` — товары

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор товара |
| `seller_id` | `integer` | NN, FK → `sellers.id` (RESTRICT) | Продавец товара |
| `category_id` | `integer` | NN, FK → `categories.id` (RESTRICT) | Категория товара |
| `title` | `varchar(400)` | NN | Название товара |
| `description` | `text` | — | Описание товара |
| `price` | `numeric(12,2)` | NN, CK `>= 0` | Текущая цена |
| `is_active` | `boolean` | NN, DEF `TRUE` | Флаг «товар в продаже» |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата добавления |

---

## 5. `stock` — остатки товаров

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `product_id` | `integer` | PK, FK → `products.id` (CASCADE) | Товар (связь 1:1 с товаром) |
| `quantity` | `integer` | NN, DEF `0`, CK `>= 0` | Количество на складе |
| `updated_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата последнего обновления остатка |

> Отдельная таблица (а не столбец в `products`) — чтобы вынести «горячо обновляемые» данные и упростить блокировки при оформлении заказов.

---

## 6. `carts` — корзины

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор корзины |
| `user_id` | `integer` | NN, FK → `users.id` (CASCADE) | Владелец корзины |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата создания корзины |

---

## 7. `cart_items` — позиции корзины

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `cart_id` | `integer` | PK (составной), FK → `carts.id` (CASCADE) | Корзина |
| `product_id` | `integer` | PK (составной), FK → `products.id` (CASCADE) | Товар |
| `quantity` | `integer` | NN, DEF `1`, CK `> 0` | Количество единиц товара |

> Составной PK `(cart_id, product_id)` гарантирует, что один товар в корзине — одна строка (а не две с разным количеством).

---

## 8. `addresses` — справочник адресов пользователя

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор адреса |
| `user_id` | `integer` | NN, FK → `users.id` (CASCADE) | Владелец адреса |
| `city` | `varchar(100)` | — | Город |
| `street` | `varchar(200)` | — | Улица |
| `house` | `varchar(20)` | — | Дом |
| `apartment` | `varchar(10)` | — | Квартира/офис |

---

## 9. `orders` — заказы

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор заказа |
| `user_id` | `integer` | NN, FK → `users.id` (RESTRICT) | Покупатель |
| `status` | `varchar(40)` | NN, DEF `'pending'`, CK `IN ('pending','confirmed','cancelled','completed')` | Статус заказа |
| `total_amount` | `numeric(12,2)` | NN, CK `>= 0` | Сумма заказа |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата оформления |

---

## 10. `order_items` — позиции заказа

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `order_id` | `integer` | PK (составной), FK → `orders.id` (CASCADE) | Заказ |
| `product_id` | `integer` | PK (составной), FK → `products.id` (RESTRICT) | Товар |
| `quantity` | `integer` | NN, CK `> 0` | Количество единиц |
| `unit_price` | `numeric(12,2)` | NN, CK `>= 0` | Цена за единицу **на момент заказа** (снапшот) |

> `unit_price` дублирует `products.price` **намеренно** — фиксирует историческую цену, как в чеке.

---

## 11. `payments` — платежи по заказам

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор платежа |
| `order_id` | `integer` | NN, FK → `orders.id` (RESTRICT) | Оплачиваемый заказ |
| `amount` | `numeric(12,2)` | NN, CK `>= 0` | Сумма платежа |
| `status` | `varchar(30)` | NN, DEF `'pending'`, CK `IN ('pending','paid','failed','refunded')` | Статус платежа |
| `paid_at` | `timestamptz` | — | Момент оплаты; `NULL`, пока платёж не проведён |

---

## 12. `deliveries` — доставки

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор доставки |
| `order_id` | `integer` | NN, FK → `orders.id` (CASCADE) | Заказ |
| `address_id` | `integer` | FK → `addresses.id` (SET NULL) | Ссылка на исходный адрес из справочника (опционально) |
| `city` | `varchar(100)` | NN | Город доставки (снапшот) |
| `street` | `varchar(200)` | NN | Улица (снапшот) |
| `house` | `varchar(20)` | NN | Дом (снапшот) |
| `apartment` | `varchar(10)` | — | Квартира (снапшот) |
| `delivery_status` | `varchar(30)` | NN, DEF `'pending'`, CK `IN ('pending','shipped','in_transit','delivered','cancelled')` | Статус доставки |
| `delivery_date` | `timestamptz` | — | Дата доставки; `NULL`, пока не доставлено |

> Поля `city/street/house/apartment` — снапшот адреса на момент оформления, чтобы редактирование справочника `addresses` не «переписывало» историю.

---

## 13. `reviews` — отзывы на товары

| Столбец | Тип | Ограничения | Назначение |
|---|---|---|---|
| `id` | `integer` | PK, IDENTITY | Идентификатор отзыва |
| `user_id` | `integer` | NN, FK → `users.id` (CASCADE) | Автор отзыва |
| `product_id` | `integer` | NN, FK → `products.id` (CASCADE) | Товар |
| `score` | `integer` | NN, CK `BETWEEN 1 AND 5` | Оценка от 1 до 5 |
| `comment` | `text` | — | Текст отзыва |
| `created_at` | `timestamptz` | NN, DEF `CURRENT_TIMESTAMP` | Дата отзыва |

> UQ `(user_id, product_id)` — один пользователь может оставить только один отзыв на товар.
